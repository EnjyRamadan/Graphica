# Graph Search AI Tool

## Overview

This tool provides solutions for AI graph search problems using popular algorithms like **BFS (Breadth-First Search)**, **DFS (Depth-First Search)**, **UCS (Uniform Cost Search)**, **Greedy Search**, and **A\***. It helps efficiently find optimal paths and solve complex search tasks in graph-based environments.

## Features

- **Breadth-First Search (BFS):** Explores the neighbor nodes first before moving to the next level.
- **Depth-First Search (DFS):** Explores as far as possible along each branch before backtracking.
- **Uniform Cost Search (UCS):** Expands the least cost node, ensuring the optimal path in weighted graphs.
- **Greedy Search:** Uses a heuristic to choose the next node, aiming for quick solutions.
- **A\* Search:** Combines UCS with heuristics for efficient and optimal pathfinding.

## Interface Overview

### 🚀 **Graphica** - AI Graph Search Tool

**Graphica** is an intuitive tool designed to solve graph-based AI search problems using advanced algorithms like **BFS**, **DFS**, **UCS**, **Greedy**, and **A\***. With an interactive interface, users can easily create, edit, and solve graphs for optimal pathfinding.

### 🖥️ **Interface Overview**

- **Navigation Bar:**  
  - **Home:** Return to the main dashboard.  
  - **About:** Learn more about Graphica’s features.  
  - **Graphs:** Explore graph-related tools and options.

- **Main Controls:**  
  - **Add Node:** Add new nodes to the graph.  
  - **Edit Node:** Modify existing node properties.  
  - **Delete:** Remove nodes or edges.  
  - **Edit Edge:** Adjust edge weights or properties.  
  - **Re-Edge:** Reconfigure connections between nodes.  
  - **Strategy Selector:** Choose from BFS, DFS, UCS, Greedy, A\* algorithms.  
  - **Select Goals:** Define the start and goal nodes for pathfinding.  
  - **Solve:** Execute the chosen algorithm to find the optimal path.

### ⚙️ **Key Features**

- Dynamic node and edge management.
- Real-time visualization of graph traversal.
- Support for weighted and unweighted graphs.
- Flexible algorithm switching with instant results.
